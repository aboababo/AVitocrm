# 📚 Руководство пользователя OSAGAMING CRM

## 🎯 Что это за программа?

**OSAGAMING CRM** — это система управления клиентами для игрового бизнеса. Она помогает:

- 👥 Вести учёт клиентов
- 💬 Управлять коммуникацией с клиентами
- 📊 Отслеживать статистику продаж
- 🔍 Быстро находить нужную информацию

---

## 🚀 Установка и запуск

### Требования к компьютеру:
- Windows 10/11, macOS или Linux
- Python 3.8+
- Node.js 16+
- Минимум 4 ГБ оперативной памяти

### Шаги установки:

**1. Установите Python:**
- Скачайте с [python.org](https://python.org)
- При установке поставьте галочку "Add to PATH"

**2. Установите Node.js:**
- Скачайте с [nodejs.org](https://nodejs.org)

**3. Запустите backend:**
```bash
cd backend
pip install -r requirements.txt
python main_simple.py
```
Сервер запустится на http://localhost:8000

**4. Запустите frontend (в новом терминале):**
```bash
cd frontend
npm install
npm run dev
```
Приложение откроется на http://localhost:3000 (режим разработки)

**5. Запуск через Docker (простой способ):**
```bash
docker-compose up --build
```
Приложение будет доступно на http://localhost:8000

## 🔑 Первый вход

### Тестовые данные:
```
Email: admin@osagaming.com
Пароль: password
```

### Как войти:
1. Откройте http://localhost:8000 (при использовании Docker) или http://localhost:3000 (в режиме разработки)
2. Введите email и пароль
3. Нажмите "Войти"

## 🔧 Решение проблем

### Программа не запускается

**Проверьте:**
- Установлен ли Python (`python --version`)
- Установлен ли Node.js (`node --version`)
- Свободны ли порты 3000 и 8000

### Ошибка входа

**Решения:**
- Проверьте данные: admin@osagaming.com / password
- Удалите `backend/crm.db` и перезапустите backend

### Программа работает медленно

**Решения:**
- Закройте лишние вкладки в браузере
- Освободите оперативную память
