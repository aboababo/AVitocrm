# Модульная структура JavaScript для чатов

## Структура модулей

```
backend/static/js/chats/
├── main.js                 # Главный файл инициализации
├── modules/
│   ├── state.js            # Управление состоянием приложения
│   ├── api.js              # API запросы к серверу
│   ├── render.js           # Функции рендеринга UI
│   ├── utils.js            # Вспомогательные функции
│   └── handlers.js         # Обработчики событий и функции для HTML
└── chats.js                # Старый файл (можно удалить после полной миграции)
```

## Использование

### Вариант 1: ES6 модули (рекомендуется для разработки)

В шаблоне `chats.html` используется:
```html
<script type="module" src="{{ url_for('static', filename='js/chats/main.js') }}"></script>
```

### Вариант 2: Собранный bundle (для production)

1. Установите зависимости:
```bash
npm install
```

2. Соберите bundle:
```bash
npm run build
```

3. Обновите шаблон для использования bundle:
```html
<script src="{{ url_for('static', filename='js/chats/chats.bundle.js') }}"></script>
```
